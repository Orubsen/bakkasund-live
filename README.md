# Bakkasund LIVE 2027 • Kassholmen, Austevoll

Offisiell festivalside for **Bakkasund LIVE 2027**, en eksklusiv kystfestival som for første gang arrangeres sommeren 2027 på den private holmen Kassholmen i Bakkasund, Austevoll.

## 🌊 Om Festivalen
- **Lokasjon:** Kassholmen, Austevoll (Vestland)
- **Tidspunkt:** Sommeren 2027
- **Kapasitet:** Kun 600 festivalpass
- **Båttransport:** «Kassholmen Express» i skytteltrafikk kontinuerlig mellom Bakkasund kai og Kassholmen
- **CEO & Grunnlegger:** Roger Alræk (`roger.alraek@gmail.com`)

## 🎫 Billettpriser
- **Dagspass (1 dag):** 800,- NOK
- **Festivalpass (2 dager):** 1 499,- NOK
- **Kassholmen VIP-pass:** 2 099,- NOK

## 🚀 Teknisk Stakk
- **Framework:** React 19, Vite, React Router 7
- **Styling:** Tailwind CSS v4
- **Hosting & Auth:** Netlify + Netlify Identity / GitHub OAuth
- **Audio:** Web Audio API synth (kystlyd)
- **Ikoner:** Lucide React

## 📦 Kjøre lokalt
```bash
npm install
npm run dev
```

For produksjonsbygg:
```bash
npm run build
npm run preview
```
